# 读记服务器 ReadSync — 原始需求文档

> 本文件是项目立项时的需求原文，原样保留作为验收依据。
> 实现说明与差异见 [实现对照](#实现对照) 一节，以及 [security.md](./security.md)。

支持多种协议的网盘，包含 WebDAV、对象存储等，也加入了 kosync（koreader）协议等特殊协议，其他不支持的协议可以后续通过插件的形式实现。

## 一、项目要求：

## 1. 总体

1. 需要可以linux服务器本地部署以及Docker，分为前端+后端。
1. 使用git进行版本管理，每一个版本使用中版本信息显示在前端网页底部和后端启动输出内。
1. 本地部署应该提供一键部署功能，即通过Shell脚本文件进行快速部署，shell里应提供github加速链接。

## 2. 前端

1. 前端采用Tailwindcss来编写，采用墨水屏样式，分为白天/夜晚模式，以及跟随系统设置。
2. 打开首页应根据登录状态，未登录状态下跳转到"登录/注册"页面，在此页面下，可以进行登录/注册操作；登录状态下进入首页。
3. 登录后，网页顶部应为导航栏，导航栏包含"首页"、"阅读状态"、"个人书库"、"设置"。
4. "登录/注册"页面也应提供忘记密码入口。
5. "首页"下用户可以自定义显示内容，包含阅读时间、阅读平台等，通过图表等形式显示。点击任意图表可以显示详细信息。
6. "阅读状态"下可以看到当前阅读书籍、阅读时长、最后一次阅读时间、总体阅读情况等用户参考的内容，也采用图表的形式显示。
7. "个人书库"下，用户可以维护自己的书库，但由于本地存储有限，通常采用其他存储方式，例如其他平台WebDAV、对象存储存储，本地仅作计算md5、书本信息和版本记录、阅读书籍文件中转等功能。
8. "设置"下，用户可以针对账号安全进行设置，包含基础设置、设置2fa验证（验证器、通行密钥），也可以管理阅读平台和同步链接或同步账号（WebDAV、对象存储、kosync协议等）。
9. 设置管理后台，仅管理员权限账号（网站初始化时，应注册管理员账号）可显示，网站管理内可以针对用户上传的文件大小、类型进行限制管理等管理，添加开发者邮件API设置（例如Resend等类似网站）实现验证码发送、通知的邮件发送；用户管理内可以进行创建、删除、重置密码、设置/取消等操作，密码通过不对称加密的方式进行存储，私钥存在服务器本地内，用户的密码不可明文传递，添加邀请码注册（可以后台开启/关闭该功能）；插件管理页面，可以上传插件，其他未说明的内容，请自行添加。

## 3. 后端

1. 后端需要有CLI以及后台控制。前端能操作的功能，后端也应可以通过指令实现。

2. 采用标准的日志输出，方便问题排查。

## 4. 其他内容

1. 编辑插件开发指南，方便开发开发者开发和系统识别。
2. 由于不同的同步格式，需要系统支持各种文件类型，包含\*.zip、\*.json等常见文件类型。
3. 开发一个统一的同步接口，提供接口参考文件，方便其他阅读软件开发者接入自己软件。

### 已知差异与未完成项

1. **密码存储方式**（前端 9）：需求原文为「密码通过不对称加密的方式进行存储」。实现改为「传输用 RSA-OAEP 加密、存储用 Argon2id 单向哈希」。原因：非对称加密是可逆的，一旦私钥泄露即等于全站明文密码泄露；密码存储的正确做法是单向哈希。需求中真正重要的两条约束（私钥在服务器本地、密码不明文传递）均已满足。详见 [security.md](./security.md)。

2. **KOSync `/users/create` 的邮箱**：该协议不传邮箱，服务端以 `<用户名>@kosync.local` 占位。这类账号需通过「忘记密码」补齐真实邮箱后才能使用 Web 界面。

3. **插件停用不卸载路由**：Fastify 无法在运行时移除已注册的路由，因此停用插件后其协议 URL 会保留到下次重启（钩子与插件代码已不再执行）。启用插件同样需要重启才能挂载路由。

4. **插件权限模型是约束而非沙箱**：`http` 与 `fs:data` 权限会真正影响注入的能力，但插件运行在同一进程内，无法抵御恶意代码。详见 [plugin-development.md](./plugin-development.md#九安全须知)。

5. **WebDAV / 本地存储的列表分页**：两种协议都没有通用游标，`browse` 接口一次性拉取后在内存分页（S3 使用 `ContinuationToken` 正常分页）。

6. **S3 上传会先缓冲成 Buffer**：`PutObjectCommand` 需要已知内容长度，超大文件上传时内存占用较高。

7. **通行密钥的 challenge 存在内存中**：仅支持单实例部署（自托管场景下可接受），多实例部署需要改为共享存储。

8. **浏览器要求 HTTPS**：密码加密依赖 WebCrypto，仅在安全上下文（HTTPS 或 localhost）可用。HTTP 访问时前端会给出明确提示。
