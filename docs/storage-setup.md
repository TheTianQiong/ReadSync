# 存储后端配置指南

ReadSync 本地只存书目元数据、MD5 与版本记录，**书籍文件放在你自己指定的存储后端上**。本文讲怎么把后端配上、各服务商该填什么、以及配完必须做的几步。

目前支持三种驱动：**本地磁盘**、**WebDAV**（坚果云 / Nextcloud）、**S3 兼容对象存储**（R2 / OSS / COS / MinIO / AWS S3）。插件还可以提供更多。

---

## 一、入口

用管理员账号登录 → 顶部导航 **设置 → 存储管理**（地址是 `/settings/storages`）→ **新建存储**。

选好「类型」后表单会切换成对应的字段。填完保存，再点该存储的 **测试** 确认连通。

> 站点设置里的「允许用户自行配置存储后端」关闭后，普通用户看不到这个页面，只能用管理员配好的存储。适合多用户共用一套对象存储的场景。

---

## 二、配完必须做的两步

**1. 设为默认存储**

上传书籍时如果没指定存储，服务端会用「默认存储」。**没有任何默认存储时，上传会直接失败**并提示「尚未配置默认存储」。

在存储列表里把要用的那个设为默认（或在编辑里勾选「设为默认」）。同一用户最多只能有一个默认。

**2. 跑一次「测试」**

点存储卡片上的 **测试** 按钮，它会实际访问一次后端并把结果写回。列表上会显示最近一次测试的时间与结果，之后出问题也能据此判断是凭据过期还是网络不通。

---

## 三、S3 兼容对象存储

这是功能最完整的一种：支持**预签名直传**（浏览器直接传给对象存储，不经过服务器）与**预签名下载重定向**（下载不走服务器带宽）。

### 3.1 字段说明

| 字段 | 必填 | 说明 |
|---|---|---|
| 名称 | 是 | 仅用于区分，如「R2 书库」 |
| Endpoint | 是 | 服务商的 S3 API 地址，**带协议、不带桶名**，如 `https://xxx.r2.cloudflarestorage.com` |
| Region | 否 | 大多数兼容服务填 `auto` 或 `us-east-1` 即可，见下表 |
| Bucket | 是 | 桶名（不是桶的访问域名） |
| Access Key | 是 | S3 凭据的 Access Key ID |
| Secret Key | 是 | S3 凭据的 Secret Access Key |
| 对象前缀 | 否 | 该存储下所有文件的前缀，如 `readsync/`。多个应用共用一个桶时用它隔离 |
| 寻址风格 | 否 | `path`（默认，MinIO/OSS 需要）或 `virtual-host`（AWS S3 常用） |

凭据会以 **AES-256-GCM 加密**落库，接口返回时一律脱敏（只保留首尾字符），编辑时留空即表示不修改。

### 3.2 各服务商怎么填

| 服务商 | Endpoint | Region | 寻址风格 | 凭据从哪来 |
|---|---|---|---|---|
| **Cloudflare R2** | `https://<账户ID>.r2.cloudflarestorage.com` | `auto` | `path` | R2 → Manage R2 API Tokens，权限选 Object Read & Write |
| **阿里云 OSS** | `https://s3.oss-cn-hangzhou.aliyuncs.com` | `oss-cn-hangzhou` 等 | `path` | RAM 控制台建子账号，授予该 Bucket 的读写权限 |
| **腾讯云 COS** | `https://cos.ap-guangzhou.myqcloud.com` | `ap-guangzhou` 等 | `path` | 访问管理 → API 密钥 |
| **MinIO** | `http://<主机>:9000` | `us-east-1` | `path` | MinIO 控制台 → Access Keys |
| **AWS S3** | `https://s3.us-east-1.amazonaws.com` | `us-east-1` 等 | `virtual-host` | IAM 用户，`s3:PutObject` / `s3:GetObject` / `s3:DeleteObject` / `s3:ListBucket` |

账户 ID 在 R2 控制台右侧栏或桶的 S3 API 地址里；阿里云/腾讯云的 region 换成你桶实际所在的地区（Endpoint 里的那一段）。

> **对象存储没有目录概念**，界面里看到的 `books/1/ab/` 只是 key 里的命名约定，用来让组织方式看起来像目录。删除「目录」需要逐个删对象。

### 3.3 用预签名直传还要多一步

如果你想在「站点设置 → 上传方式」里选**预签名直传**（浏览器把文件直接传给对象存储，不经过服务器），桶上还必须配 **CORS**，否则浏览器会拦掉请求。见 [对象存储 CORS 配置](storage-cors.md)。

不走直传（用分片上传）则不需要配 CORS。

## 四、WebDAV（坚果云 / Nextcloud）

| 字段 | 说明 |
|---|---|
| 服务器地址 | 带协议与结尾斜杠，如 `https://dav.jianguoyun.com/dav/` |
| 用户名 | 账号 |
| 密码 | **坚果云要用「应用授权码」**，不是登录密码 —— 在 账户信息 → 安全选项 → 添加应用密码 |
| 根目录 | 留空表示账号根目录；填了则所有文件放在该目录下 |

WebDAV 不支持预签名，传大文件时用分片上传。

---

## 五、本地磁盘

| 字段 | 说明 |
|---|---|
| 相对路径 | 相对**服务器数据目录**的路径，默认 `storage`（即 `data/storage`）。禁止绝对路径与 `..` |
| 容量配额 | 0 表示不限制 |

**本地磁盘同样不支持预签名直传**。另外要注意：文件存在服务器本机，换机器或重装前记得连同数据目录一起备份。

---

## 六、多存储怎么用

- **默认存储**决定「不指定时文件放哪」。
- 上传书籍时可以在上传对话框里**单独选一个存储**，那本书就存在那里。
- 同一用户最多一个默认存储；删除仍有书籍引用的存储会被拒绝（先删书或迁移）。
- 对象前缀让多个应用共用一个桶而不互相干扰，例如 ReadSync 用 `readsync/`、别的程序用 `backup/`。

---

## 七、常见报错

| 提示 | 原因 |
|---|---|
| 尚未配置默认存储 | 没设默认。去存储管理里设一个 |
| 对象存储认证失败，请检查 Access Key / Secret Key 与权限 | 凭据错，或子账号没有被授予该桶的读写权限 |
| 对象存储 Bucket 不存在或无权访问 | 桶名拼错，或 Endpoint 与桶不在同一区域 |
| Endpoint 格式不正确 | 漏了 `https://`，或把桶名写进了 Endpoint |
| 上传时报「存储『xxx』不支持预签名直传」 | 当前是本地磁盘或 WebDAV。前端会自动回退到分片上传；也可以把「上传方式」改回分片 |
| 上传成功但下载 404 | 对象前缀在配置前后被改过，老文件的位置与新前缀对不上 |
| 直传时报「无法连接对象存储」 | 桶的 CORS 没配。见 [storage-cors.md](storage-cors.md) |

排查顺序建议：先点 **测试** 看连通性 → 再点 **浏览** 看能不能列出对象 → 最后试传一本小书。这样能把「凭据问题」「路径问题」「上传问题」分开，不用一次猜一堆。
